# Проверка текущей версии

Выпуск проверен 22 ноября 2026. Миграция 014 добавляет причину переноса, срок ответа и отметку о запросе уточнения. Контрольные суммы миграций 001–013 сохранены.

На Node.js 24.22.3 и 26.13.1 прошли все 57 тестов. Проверка Svelte и TypeScript прошла без ошибок и предупреждений. `npm audit --omit=dev` вернул 0 известных уязвимостей. После восстановления резервной копии в отдельную базу контрольные количества записей совпали.

## Чистая установка

На Windows проверили установку из архива с Node.js 26.13.1 и PostgreSQL 18.7. Установщик создал пустую базу. Приложение применило 14 миграций, команда `seed` загрузила демонстрационные данные. Скриншоты и видео сняты с этой установки.

[Docker Compose v5.7.0](https://github.com/docker/compose/releases/tag/v5.7.0) проверил через `config --quiet` базовую конфигурацию и варианты CUDA и Vulkan. Сборка и запуск самих контейнеров требуют Docker Engine. На машине проверки выполнен нативный запуск.

## Автоматические проверки

`pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\manage.ps1 check` проверяет Svelte, TypeScript и service worker. `pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\manage.ps1 test` создаёт отдельную базу с уникальным именем, применяет миграции, наполняет её учебными данными и запускает production-сборку. После тестов удаляются только база этого прогона и его сборка. Файлы тестов выполняются последовательно из-за общей тестовой БД; гонки проверяются параллельными HTTP-запросами внутри соответствующих сценариев.

Покрываются четыре роли, личные данные и факультеты, сессии, Origin, весь путь заявления, QR, CSV/XLSX и атомарный откат, посещаемость, учебный план и календарь, очередь деканата, общая оболочка студента, протокол чата, ограничения контекста и архитектурные границы.

Регрессии аудита: замена отменённой пары и запрет конфликтующего восстановления; устаревшая запись оценки и единственный победитель гонки; история значений; конфликт после предпросмотра импорта; отзыв назначения; неизменяемость аудита ролью приложения; отсутствие сертификата для общего обращения. Для переписки проверяются запреты чтения и записи, параллельная отправка одного сообщения, ответ деканата и уведомления без текста сообщения.

## Восстановление и поставка

`pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\manage.ps1 backup-check` создаёт дамп, восстанавливает его в новую отдельную базу и сравнивает контрольные количества записей. Рабочая база не заменяется. JSON-отчёт находится рядом с дампом.

`pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\manage.ps1 package` создаёт единый архив исходников с реестром SHA-256. Архив содержит исходники и документы. Локальные настройки, база, модель, зависимости и сборки остаются на машине.
